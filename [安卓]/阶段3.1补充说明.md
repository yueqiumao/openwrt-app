# AX6 助手 · 阶段 3.1 补充说明

版本：v1.3.0　包名：`com.ax6.luyouqi`　交付：`[安卓]/AX6助手-v1.3.0-阶段3.1-流量扫描主题.apk`

## 一、局域网/无线流量卡（更正阶段 3 的错误说明）

阶段 3 报告里写的「依赖 luci-app-vantage-traffic」是错的。网页版的流量来自 `luci-rpc getNetworkDevices` 的 `stats.rx_bytes/tx_bytes`，与 vantage-traffic 无关。

本轮真机探测（`C:\Users\1600\Doubao\ax6-probe\scan-probe.js`）确认：

- `getNetworkDevices` 返回 `br-lan`、`wan`、`lan1..3`、`phy0-ap0`、`phy1-ap0`，都带 `stats`；
- `br-lan` rx 515,135,158 / tx 4,244,138,582；`phy0-ap0` rx 196,242,088 / tx 2,154,016,021；`phy1-ap0` rx 2,952,734 / tx 14,229,677。

安卓端实现：每轮从已采集的 devs 里取 `br-lan` 与匹配 `^phy\d+-ap\d+` 的接口计数，`trafficRates` 差分算速率；无线按 AP 视角 `down = tx 差`、`up = rx 差`。网络页新增「LAN / WiFi 收发流量」卡，逐行显示 SSID/接口名、实时收发、累计收发。

## 二、WiFi 周边扫描

真机探测结果：`iwinfo scan {"device":"phy0-ap0"}` 返回 code 0、19 条；`phy1-ap0` 返回 35 条。字段为 `bssid / mode / band / channel / mhz / signal / quality / encryption{enabled,wpa,authentication,ciphers}`，部分隐藏网络的 `ssid` 为空。

实现：`RouterRepository.scan(ifname)` 解析并按 signal 降序；加密标签映射为「开放 / WPA2-PSK / WPA3-SAE / WPA-PSK」；设置页「工具 · 扫描周边 WiFi」可切换 5G / 2.4G 接口、点「开始扫描」，结果列出 SSID（隐藏显示 `(隐藏 SSID)`）、信号、信道、频段、加密、BSSID。只读操作，不改配置；进行中会避开 3 秒轮询（同一 Mutex 串行）。

## 三、主题切换

- `Ax6Tokens` 由静态常量改为随 `dark` 状态返回的 getter，取色值仍严格来自网页版 `:root` 与 `html[data-theme="light"]`。
- 设置页「外观」卡：切换深色/浅色，写入 `SharedPreferences("ax6_ui")` 的 `theme_dark`，重启 App 保持。
- `Ax6Theme(darkTheme = …)` 与 Material3 配色同步切换，避免弹窗、输入框仍是深色。
