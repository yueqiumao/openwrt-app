# AX6 助手 · 阶段 4 报告（视觉对齐 + 布局修订）

版本：v1.3.0　包名：`com.ax6.luyouqi`　交付：`[安卓]/AX6助手-v1.3.0-阶段4-视觉与交互.apk`
md5：`1b430e95afa4a45786c9b00575b14329`

## 一、视觉层（一次性做完六层）

1. **等宽数字**：新增 `numStyle()`，`fontFeatureSettings="tnum"`；首页速率、六宫格数值、在线终端三个数字、连接数、运行时间全部改用它，速率 9→10 KB/s 不再左右跳。
2. **卡片质感**：卡片改为 `shadow(14dp)` + 垂直渐变底（深色 `#17222E→#0D151D`，浅色纯白→`#FAFCFF`）+ 渐变描边（上亮下暗）；六宫格 `shadow(8dp)` 同款处理。不再是不透明色块加一条线。
3. **图表**：折线改三次贝塞尔平滑（每段用相邻点均值做控制点，避免过冲）；线下渐变填充 24%→2%；网格 4 条；下载线 3dp、上传线 2.5dp。
4. **强调色**：新增 `AccentSoft`（12% 底）与 `AccentEdgeSoft`（45% 描边），用于扫描页接口选中态与胶囊。
5. **动效**：tab 切换 `Crossfade`；两个弹窗（设备详情、网口详情）用 `PopIn` 缩放 0.94→1 + 淡入 180ms。
6. **间距**：页边距保持 14dp（沿用你之前明确要求，未改回 16dp），卡间距 12dp、卡内 14dp 不变。

## 二、按截图提的布局修订

1. **首页在线终端**：去掉把数字推到卡片底部的 `Spacer(weight)`，数字行紧跟标题（与左侧 CPU/内存大数字同一高度），三个数字下各自带「有线 / WiFi / 全部」小字，「全部」贴右。
2. **网络页合并**：物理网口与 LAN/WiFi 流量合成一张「网络接口」卡，逐条平铺：
   - 每条左侧：状态圆点 + 名称（WAN/LAN1…、LAN、SSID），下方小字为速率双工或接口名；
   - 每条右侧：实时 ↓↑、累计 ↓↑ 两行。
   - 已删除原来的 2×2 格子和独立流量卡。
3. **设置页**：连接卡删掉「账号」「认证方式」，只留路由器地址与轮询周期；设备卡去掉右上角「10 台 WiFi」胶囊；固件版本改为右侧对齐、最多两行（`KvRow` 的 value 改为 `weight(1f)` + 右对齐）。
4. **扫描周边 WiFi 改为独立页**：设置页只留一行入口「扫描周边 WiFi →」；点击进入全屏页（隐藏底部导航），页内有返回箭头、接口选择卡（5G / 2.4G 可切）、右上「开始扫描」、结果卡（SSID / 频段·信道·加密 / BSSID / 信号 dBm + 强中弱）。

## 五、未验证 / 取舍说明

1. 真机未看：浅色下卡片阴影浓度（14dp 可能偏重）、深色下渐变底是否够“玻璃感”、Crossfade 切换时页面高度跳变。
2. 图表平滑用的是相邻中点控制点，极端尖峰可能仍略显圆；若你要更贴近网页版，可换单调三次插值。
