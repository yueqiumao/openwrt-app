## 二、网络页结构（对齐网页版 renderNetwork）

1. **上行 WAN · IPv4**：状态胶囊、IPv4 地址、协议（DHCP / PPPoE / 静态 / 未配置）、物理接口、网关、DNS、剩余有效期、已连接时长、实时速率。
2. **上行 WAN · IPv6**：全部 IPv6 地址逐条（等宽自适应字号，单行完整）、协议（DHCPv6 客户端）、分发前缀（PD）、网关、DNS、剩余有效期、已连接时长。
3. **物理网口**：2 列格子，名称 + 已连接/未插线、速率与双工、实时收发、累计收发。
4. **无线网络**：每个 SSID 一张子卡，SSID、ifname、频段、信道、客户端数、加密方式；整卡显示合计在线数。
5. 底部说明：LAN / WiFi 分接口流量依赖 `luci-app-vantage-traffic`，本机未安装，故不显示流量卡。

## 三、设置页结构

1. **连接**：路由器地址、账号、认证方式（ubus 直连）、轮询周期（3 秒）。
2. **设备**：主机名、设备型号、目标平台、固件版本、运行时长、在线终端数。
3. **数据源诊断**：沿用探测结果（LuCI RPC / 表单登录 / 连接数 / 端口映射），附「只读、不改配置」说明。
4. **操作**：立即刷新全部数据、断开连接（红字）；明确标注「重启路由器暂未实现」。
5. **关于**：版本 v1.3.0、原生直连架构、包名、视觉参考。
